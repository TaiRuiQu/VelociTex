## 实际验证

`tests/fixtures/p1.json` 冻结 **64 valid / 12 invalid**，分为 atoms、spacing、
scripts、fractions、radicals、styles、macros 及错误类。全部基本用例在有效/错误
两方面均运行；6 个代表公式扩展为 16/24/32 DIP、100/125/150/200% 栅格密度、
明暗场景，合计 **202 组**。这个数字是场景数，不冒充 202 个独立公式。

- 源码与 npm 发行包的上游 AST 一致；C# 紧凑树经独立投影后，64 个语义对照通过。
- JIT 和真实 Native AOT 各 202 组：尺寸、字形/字体/位置、分式线、根式数量和
  实际 SVG 视口路径变换、规范 MathML 均通过；原文 annotation 精确保留。
- 最大 advance 差 **0.05325 DIP**、ascent **0.015705 DIP**、depth **0.01568 DIP**；
  字形 x 最大差 **0.039 DIP**、字形基线最大差 **0.018125 DIP**。没有拟合平移或缩放。
- JIT/AOT 语义、几何、诊断完全一致，**606 个导出文件逐字节相同**
  （202 × PNG/SVG/MathML）；每个 PNG 独立解码，每个 SVG 在锁定 Chrome 中实际
  打开，网络阻断且无外部字体/资源。全部 native↔SVG 边缘检查通过，无边缘裁切。
- **5,754 项额外断言**包含 512 个确定性生成表达式、512 个错误变体、重新编译
  恢复，以及 Unicode、宏作用域/覆盖、预算、取消、会话回滚、结果缓冲隔离、
  100 次独立工作区并发及 100 次 renderer 创建/释放。它们不扩大兼容用例分母。
- PNG/SVG 的文件与不可 seek Stream 输出逐字节相同，调用者的 Stream 保持打开；
  MathML 的字符串/流一致；跨线程、错误 renderer、disposed preparation 均拒绝。
- 真实 AOT WinUI 4 个公式及 1 个错误源，10 张自动 HWND 截图：明暗×4 密度、窄窗、

## 栅格差异的实况

没有把语义/几何通过当成所有像素指标通过。202 组 KaTeX 浏览器对照中，原定
95% 双向边缘自动指标 **72 组通过、130 组超限**；原生与独立 SVG 的对应指标则
全部通过，最差方向约 97.4%。原始失败、分类型统计、额外透明参考 alpha 指标
均保留在 `artifacts/p1/{jit,aot}/image-check.json`。

已检查全部 202 对原点/基线对齐联系表（9 页），并在根式修正后重新检查受影响页。
剩余差异表现为字体栅格提示、抗锯齿/对比度和不同的实际子像素栅格相位：
72 对明暗浏览器几何完全一致，但前景掩码全部改变；原生同阈值掩码保持一致。
原始像素的墨迹边界相对 TTF/路径最大差：native 约 1.0141 device px，浏览器约
1.6939 device px；两者边界差最大约 1.7106 device px。额外透明参考并未让这些
自动失败消失，因此没有改测量阈值或隐去失败。

`compatibility/p1-raster-review.json` 按 PNG/SVG/参考图散列记录 130 项已复核的
渲染差异。这是用户已允许的轻微抗锯齿差异记录，**不是 130 项自动通过**。
`p1-images.mjs --reviewed` 只认可完全相同图像的既有复核；任何新图、裁切、缺字、
native/SVG 不一致或语义/几何错误都不能用这份清单清除。

检查实际修复了三类问题：D2D 默认 alternate 填充抵消根号横线，改为上游 nonzero
语义；16 DIP 分式 CSS 边框的最小整像素绘制约束；根式 SVG 的 `width:100%`
覆盖 `400em` 属性，必须使用真实视口与 viewBox 的 slice 比例。最后一项修正后，
独立根号左侧笔画在 32 DIP/200% 的双向覆盖从约 58%/59% 提高到 100%/99.6%。
旧图与调查保留于 `artifacts/p1/review/before-radical-fix/`，没有把真实数学错误归入
抗锯齿例外。P0 自然高度测量也改为直接 strut，由既有 raw DOM 重派生，旧截图未改。

## 分配与资源基线

开发机仍是 P0 的 i5-12400F / Windows build 26200；没有旧 CPU。六个 P1 基本公式
各 1,000 次完整同步编译，共 6,000 次，工作区预热、无公式缓存，包含选项校验、
展开、解析、布局、绘制指令与独立结果分配；不含 native prepare/draw/编码。
