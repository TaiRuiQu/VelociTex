# P3 下游原生显示迁移记录

日期：2026-10-19。`oh-my-study` 的默认题目显示链已经迁移到固定的本地
`0.2.0-preview.1` 包；正文混排由下游宿主负责，单公式语义及排版仍以 KaTeX
**0.19.0 / 6ea2dc97188f0cc282e05a9690418ae7fe5457ba** 为唯一基线。
这证明显示调用边界完成迁移，不意味着全部有效数学命令已经兼容，更不是 1.0 声明。

## 实现及用户改动保护

- `NativeReadingSession` 是正文、选项、表格、小题、反馈和列表预览的共同入口。
  默认转到 `NativeFormulaReadingSession`；正常显示不再调用旧 LaTeX 转换器或 Typst。
  保留原有 `DocumentText.Split` 的分隔边界；裸数学识别不再由旧转换器的支持列表筛选。
- 宿主 `NativeFormulaParagraph` 使用真实 DirectWrite 文本布局及静态 Native AOT
  inline-object 回调，按实际编译结果的宽、高和基线嵌入公式。正文使用既有非衬线字体，
  公式使用原版 KaTeX 字体；正文换行归宿主，长单公式提供横向滚动。
- 块公式直接由 `MathView` 绘制。两条路径均从原生绘制结果提交到 Composition，
  PNG/SVG 不充当正常显示中间物。无效或当前未支持的输入保留原文。
- 原文整段 Ctrl+C、菜单复制整段或单公式、整段及每个公式的只读 UIA Value 已实测。
  公式提供名称与源文本；没有宣称结构化语音导航或屏幕阅读器音频验收。
- 16 MiB / 512 项结果缓存使用库的节点及绘制数据估算器；最多 64 个待编译请求、
  一个编译槽。外部 CJK provider 重试不缓存完整结果，其独立轮廓缓存仍有双上限。
  原有列表 generation/cancellation 与 500 行虚拟化保留。
- 同一 UI 线程共享有计数生命周期的私有字体 renderer、WARP 设备和 Composition
  graphics device。系统正文使用 DirectWrite shared factory；每段仍拥有自己的布局、
  表面及 prepared result，卸载时释放。
- 内部临时回滚开关 `OHMYSTUDY_LEGACY_FORMULA_DISPLAY=1` 可选择原显示链。
  它不是产品设置，后续稳定期结束应删除。打印/PDF 继续使用原 Typst 服务，未删除工具链。

下游最初已有大量用户未提交改动和未跟踪文件。修改前保存精确字节及 dirty status，
没有在下游暂存或提交。交付的 [迁移补丁](../../integration/oh-my-study/p3.patch)
仅相对于该 dirty baseline；其 [清单](../../integration/oh-my-study/p3.manifest.json)
包含 **22 个受保护路径、18 个改动** 的 raw / LF canonical 前后 SHA-256。
在隔离副本 `git apply --check`、实际 apply 及全部结果哈希验证通过。
用户原有删除的 `migration-progress.md` 等无关修改不在补丁内。

普通库的四个 `packages.lock.json` 保持原始字节。全局 AOT 发布使用四个独立
`packages.aot.lock.json`，三种 App 变体锁均包含固定本地包；普通 Debug、AOT
锁定构建及 AOT 后普通锁定恢复均通过。依赖源映射将 `VelociTex.*` 固定到本地 feed。

## 复现与未验证项

在迁移后的下游工作区运行：

```powershell
dotnet build src/OhMyStudy.App/OhMyStudy.App.csproj -c Debug -p:Platform=x64 -p:RestoreLockedMode=true
dotnet publish src/OhMyStudy.App/OhMyStudy.App.csproj -c Release -r win-x64 -p:Platform=x64 -p:PublishAot=true -p:RestoreLockedMode=true -o <owned-output>
<owned-output>/OhMyStudy.App.exe --math-smoke <math-report>
<owned-output>/OhMyStudy.App.exe --preview-smoke <preview-report>
```

在 VelociTex 工作区运行：

```powershell
./tools/Verify-DownstreamDisplay.ps1 -ApplicationPath artifacts/p3/locked-aot-publish/OhMyStudy.App.exe -OutputDirectory artifacts/p3/locked-native-monitored
./tools/Verify-DownstreamDisplay.ps1 -ApplicationPath artifacts/p3/locked-aot-publish/OhMyStudy.App.exe -OutputDirectory artifacts/p3/locked-legacy-monitored -Legacy
./tools/Write-P3Evidence.ps1 -Check
```
