## 复现入口

在本仓库根目录运行，需已安装锁定的 SDK、Windows/VC++ Native AOT 工具链。
参考工具需锁定 Node/npm、Python 和相同浏览器字节；普通库消费者不需要这些。

```powershell
./verify-reference.ps1 -FullMatrix
./build.ps1 -Target All -Locked
python tools/VelociTex.Native.Probe/verify-native.py artifacts/native
python tools/Review-WinUIImages.py artifacts/winui/aot
./tools/Write-P0Evidence.ps1
```

大图、上游源码、发布产物及原始样本在 Git 忽略的 `artifacts/`；小型生成数据、
输入/输出散列、锁文件、许可证和复现工具提交到 Git。原始 Typst 比较额外需要
旁边已有下游 DLL/工具链，仅供开发比较，不构建或修改下游项目。

## 视觉检查与选型

已检查真实 AOT WinUI 窗口的浅/深色、100/125/150/200% surface 栅格密度、宽窄
窗口、卸载重载、行内对象及未采用的 RichTextBlock 对照截图。截图通过
Windows.Graphics.Capture 自动捕获实际 HWND，包含 Composition 外部 visual。
`RenderTargetBitmap` 会漏掉该 visual，不能作为此探针的验收替代。

原生 PNG 与独立浏览器打开的路径 SVG 也已检查；字形顺序、上下标、分母、根号、
矩阵行列和边界完整。P0 硬编码位置仅证明技术路径，不声称达到 KaTeX 排版阈值。
检查中修复了跨 D2D factory 几何、AOT XAML 资源遗漏、native 引用错误路径释放、
surface brush 生命周期以及校准分式文字裁切。

复制按钮通过 computer-use 功能操作，随后精确核对剪贴板中的完整段落 LaTeX。
此测试不替代视觉验收。正式 MathView 自动化语义和下游正文选择仍属于后续阶段。

## 固定与保留的预算

参考端重复噪声为 0 DIP，独立 baseline 差异在 Chromium 布局舍入范围内，保留
`validation.md` 的统一几何容差。公式有效 em 必须抵消 KaTeX 外层 1.21 放大，
TeX metrics、TTF advance、italic correction 和 ink bounds 各自保留。

保留设计中的输入/节点/展开/深度/像素等可配置上限及初始内存目标，作为 P1
待验证预算。真实解析与布局尚不存在，不能用探针输出耗时冻结它们的子阶段预算；
此项在 P1 对真实流水线校准。≤10ms 及后来 ≥10× 均未被宣称达成。
