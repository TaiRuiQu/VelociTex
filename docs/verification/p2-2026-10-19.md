## 实现

- 紧凑语义节点与显式任务栈增加积分、求和、极限及上下限、命名算符、广义分式、
  二项式、连分式、索引根式、伸缩及固定大小定界符、重音、上下横线和可标注箭头。
- matrix/pmatrix/bmatrix/Bmatrix/vmatrix/Vmatrix、smallmatrix、array、cases、
  dcases/rcases、aligned/alignedat/gathered/subarray，包含列对齐、规则线、行距。
- 宏环境/单元格作用域、分隔参数、嵌套定义 `##`、全局定义和会话回滚。
  不额外接受上游 0.19.0 未实现的 newcommand 可选默认参数。
- 59 个固定伸缩路径、10 个高定界符及 9 个延伸段生成器；运行时不解析 SVG。
- `WindowsMathTextShaper` 在完整编译内通过 DirectWrite 生成实际 CJK 字形轮廓。
  返回 em 轮廓、实际 advance、墨迹边界和实际字体名称；独立绘制结果不保留 provider。
  当前是 CJK 标量回退，不承诺复杂文字整段 shaping。其他缺字明确报错。
- `MathDocumentCache` 线程安全 LRU，默认 16MiB 估计载荷及 256 项双上限；宏、会话、
  定义输入和外部 shaping provider 均绕过结果缓存。无隐藏队列。额外 drawing decoration
  限制 262144 条；PNG/控件表面限制 4MP、8192px 单边。并非零分配。
- `MathView` 结果和描述绑定、主题/DPI 失效、完整原文 Ctrl+C、只读 UIA Value、名称及帮助；
  真实卸载后重新加载恢复。P0 探针已从公开 API 内部化。
- 三个本地包、符号包、XML API 文档、20 个原版嵌入字体及独立 MIT/OFL/RFN 许可证。
  原生导出示例和 WinUI 示例均存在，隔离消费者仅通过 PackageReference 接入。

## 性能及资源实测

同一 i5-12400F 开发机、Windows 26200；不是旧 CPU 替代。5 个独立 Release AOT 进程，
每轮 6000 次，6 大类各 1000 次，顺序固定种子洗牌，结果/语义/布局缓存关闭。
校验、解析、宏、排版、需要的 CJK 轮廓 shaping、结果分配均在计时内；无逐次强制 GC 或删异常值。

各轮整体 P95：**0.0571 / 0.0758 / 0.0550 / 0.0522 / 0.0587ms**。
完整编译同步 managed 分配 8480～56088B；冷第一遍另报，最高包括字体查询和首次初始化。
各分类分布、P50/P99/max、逐次 CSV 均保留。

首轮 1/10/50/100/1000 公式无结果缓存批次分别约 0.064/0.456/1.684/4.015/40.197ms；
重复请求实际命中数 1/10/48/97/256（CJK 外部 provider 绕过，1000 项受 256 上限淘汰）。
1000 项重复顺序测试更慢也原样报告，不冒充全部命中。清空与 GC 后 private bytes、
managed heap、handles、shaping 缓存估计载荷均记录。

native prepare、draw submit、WIC 软件 target EndDraw 完成绘制、PNG/SVG/MathML 编码单列。
首次 target/编码器有明显初始化开销；例如首轮第一项 EndDraw 49.8ms、PNG 43.9ms，
不是核心编译超时，也未伪装成稳定帧耗时。GPU present、峰值 GPU/native 内存未测。
原始数据：`artifacts/p2/workload-aot/run-{1..5}/`；JIT 对照在 `workload-jit/`。
**旧 CPU ≤10ms 验收仍未完成；没有 ≥10× 结论。**
