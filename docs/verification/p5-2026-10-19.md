P4 的原始 1058 个浏览器 AA 阈值超限仍保留为信息。没有新增像素豁免清单或改变数学

## 核对冻结产物与重建

当前 checkout 核对已有冻结 feed、锁和证据，**不重新打包**：

```powershell
./tools/Write-P5Evidence.ps1 -Check
```

如需重新执行消费者，在新输出目录使用冻结 feed 和已验证的版本锁，不覆盖历史报告/PID：

```powershell
./tools/Verify-PackageConsumer.ps1 -Version 1.0.0-rc.1 -Feed artifacts/packages/p5 -Output artifacts/p5-recheck/headless
./tools/Verify-WinUIPackageConsumer.ps1 -Version 1.0.0-rc.1 -FeedDirectory artifacts/packages/p5 -OutputDirectory artifacts/p5-recheck/winui
```

如需重建，在记录的干净源提交创建独立目录，不覆盖已冻结 feed：

```powershell
git worktree add --detach artifacts/reproduce-p5 1b0c77774418fd349c36b8b4cd0c89a135f70fba
cd artifacts/reproduce-p5
./pack-local.ps1 -Version 1.0.0-rc.1 -OutputDirectory artifacts/packages/rebuilt -Locked -VerifyDeterminism
./tools/Verify-PackageConsumer.ps1 -Version 1.0.0-rc.1 -Feed artifacts/packages/rebuilt -Output artifacts/rebuilt-consumer/headless -UpdateLocks
./tools/Verify-PackageConsumer.ps1 -Version 1.0.0-rc.1 -Feed artifacts/packages/rebuilt -Output artifacts/rebuilt-consumer/headless
./tools/Verify-WinUIPackageConsumer.ps1 -Version 1.0.0-rc.1 -FeedDirectory artifacts/packages/rebuilt -OutputDirectory artifacts/rebuilt-consumer/winui -UpdateLocks
./tools/Verify-WinUIPackageConsumer.ps1 -Version 1.0.0-rc.1 -FeedDirectory artifacts/packages/rebuilt -OutputDirectory artifacts/rebuilt-consumer/winui
```

重建会产生新的 ZIP 时间戳和整包哈希，需新锁和新消费记录；重建结果不由本次
`Write-P5Evidence -Check` 的固定哈希冒认。最终 P5 提交后的 HEAD 含交付文档，已不再
是原候选的打包源提交。外部发布必须另行取得授权。
