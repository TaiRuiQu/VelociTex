# P4 核心兼容实现与本地预览交付

日期：2026-10-19。P4 已完成约定范围内的核心注册项实现及本轮实际用例验收。
兼容基线仍为 **KaTeX 0.19.0 / 6ea2dc97188f0cc282e05a9690418ae7fe5457ba**。
交付包为 **0.4.0-preview.1**；本阶段提前完成部分 P5 打包准备，不把预览版本写成
1.0 正式发布，也不宣称旧硬件、全部平台或任意参数组合已经验收。

用户在本轮明确调整视觉要求：**“可以放宽抗锯齿不一致的要求，只需要排版正确即可。”**
因此原像素边缘阈值的超限保留为诊断信息，不再作为验收阻塞。数学语义、几何、缺字、
错序、裁切、颜色丢失及结构错误仍不能豁免；本轮没有修改用例以移除实现失败。

## 实现范围与接口

- 保留紧凑 C# 语义节点、显式解析任务栈和独立绘制数据。补齐注册的核心函数、符号、
  内置宏、环境及选项：算符与 limits、普通/广义分式、根式、固定及伸缩定界符、
  重音/上下装饰/箭头、矩阵及 array 规则线、编号/标签、CD、特殊盒、尺寸及单位。
- 增加颜色及背景边框、取消线、phantom/smash/lap、raisebox/vcenter、反射、模拟粗体、
  mathchoice/HTML–MathML 分支、显式绘制顺序和仿射状态；透明公式可以具有合法的空
  `PaintCommands`。所有输出遵循相同命令顺序，不再按 glyph/rule/path 数组类别重排。
- 宏覆盖常用定义、分隔参数、嵌套参数、let/futurelet、edef/xdef、全局修饰、条件与
  范围内内置宏行为；会话、作用域及错误/取消回滚保持显式。严格模式告警和受信任宿主
  回调有独立契约；返回结果不保留外部宏字典、会话或 shaping provider。
- 补齐 Unicode 映射与字体/文本规则。Windows provider 返回实际系统字体标量轮廓，
  并支持 DirectWrite 完整上下文文字 run；连字、组合符、ZWJ/ZWNJ、韩文分解字符、
  印度文字、泰文及阿拉伯文字均在完整编译计时内 shaping。源文本保留原字节含义，
  字形绘制可以做通用规范等价合成；不把标量逐字绘制冒充上下文 shaping。
- `MathTextRun` 保留原文、baseline、实际 advance 和所对应的独立路径范围。
  字体来自实际安装环境，当前浏览器参考与本机实际系统字体均记录，不能推导到所有机器。
- `TryCompile` 继续返回结构化失败；`CompileForPresentation` 单独支持普通语法错误的
  彩色原文结果。资源超限、取消、工作区占用等不会触发无界二次尝试。错误结果的原文、
  颜色及 MathML 与准确上游的 tolerant 展示行为独立比较。
- `DisplayWidth`、标签布局、公式 baseline、颜色/变换状态、资源上限、原文复制和 UIA
  生命周期均有实际测试。Core 仍只负责单公式，不承担宿主正文段落或自动数学换行。
- 运行时无浏览器、Node、JavaScript 引擎或 Typst 数学执行路径。WinUI 的 Windows App SDK
  自包含载荷会随上游依赖带有 WebView2 SDK/loader 文件；MathView 不实例化 WebView，
  不能将这项宿主依赖事实误写成发布目录完全没有任何 WebView 命名文件。

## 实际绘制和用户调整后的视觉要求

全部原生 PNG 独立解码，全部 SVG 在锁定 Chrome、禁用网络后真实打开。
**3843 个 native↔SVG 双向边缘场景全部通过，0 边缘裁切**。
曾实际发现两个 bold g 的 native↔SVG 边缘覆盖约 **0.933**；改为通用字形轮廓绘制，
修复后约 **0.966**，没有为某个公式改字形、阈值或缩放。

浏览器比较的旧边缘阈值仍有 **1058 个原始自动超限**，保留全部原图和指标。
这些是抗锯齿/对比度/栅格相位及细规则线像素差异，在用户新的“排版正确即可”要求下
作为信息项，不设逐项 AA 豁免清单、不将其篡改成像素阈值自动通过。
原始 RGB 覆盖、覆盖无关色向指标及准确 CSS/paint-state 颜色硬检查都保留；纯灰或
红/黄背景边界的像素混色不能单靠未预乘 hue 推断颜色丢失。

本代理实际打开 **12 组、36 张**当前 native PNG / 独立 SVG view / 浏览器原图：
彩框背景、xcancel、反射、自动标签、CD、下方箭头、曲面积分、Devanagari ZWJ、泰文、
韩文 Jamo、拉丁字母包围的阿拉伯文字、单/双撇号。未见缺字、错序、结构、裁切或颜色
丢失；彩框角部的混色属于 AA。精确输入图像及复核记录在
`artifacts/p4/representative-layout-review/review-result.json`。主任务和排版代理另有复核。

## 复现及剩余验收

```powershell
./build.ps1 -Target P4 -Locked
./verify-p4.ps1
node tools/reference/p1-reference.mjs --phase=p4 --full-matrix
./tools/Write-P4Evidence.ps1 -Check
```

后两项以保存的源、工具链、字体和语料生成/核对证据；单独参考生成不会执行 C#。
包与消费者完整命令见 `pack-local.ps1`、`tools/Verify-PackageConsumer.ps1` 和
`tools/Verify-WinUIPackageConsumer.ps1`，使用 `0.4.0-preview.1` 的独立版本化锁。

未验证：约十年前旧 CPU 和低内存实机、实际显示器 DPI 来回切换、Windows 10 最低
版本实机、硬件 GPU/驱动设备移除、精确 native/GPU 峰值及屏幕阅读器语音。
P3 下游仍固定历史 P2 包，P4 包不自动覆盖下游依赖或打印链；换包后应重新跑其验收。
