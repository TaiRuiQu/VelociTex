# 1.0.0-preview7

The browser package now renders with a standalone HTML/CSS WebAssembly engine
and the bundled KaTeX 0.19.0 stylesheet and fonts. This replaces the default
MathML presentation path from preview6. Native C++ Core, .NET and Direct2D/WinUI
remain available, with fresh benchmark measurements alongside the browser data.

- Default browser output contains visual HTML and accessibility MathML. The
  dedicated WebAssembly module runs without the JavaScript KaTeX renderer;
  SVG and legacy options retain the full-Core fallback.
- HTML, HTML-only and MathML parity passed for 3,659 valid core fixtures.
  Browser integration passed 46 formulas, including bundled CSS/font loading.
- The benchmark now times default HTML generation separately from MathML and
  from DOM replacement plus forced layout. All 36 formula occurrences are
  included in three fresh processes with 15 calibrated batches per case.
- Refreshed native/WASM/KaTeX rendering tables, charts, raw reports and package
  READMEs. Historical preview6 results and release notes remain available.

On the benchmark machine, WASM/KaTeX relative throughput is **0.91–1.03×** for
HTML generation and **0.93–0.97×** for DOM/layout work. Ratios below 1 mean WASM
is slower. These are warm measurements of this corpus; startup, download,
browser rasterization, GPU completion and screen presentation are excluded.

The combined color/accents/fonts preview has a CSS serialization difference
(declaration order and a redundant inherited color declaration). All four
preview formulas have matching computed styles and dimensions in their visible
HTML trees; the images are not claimed to be pixel-identical. All 36 timed
formula occurrences produce byte-identical default markup to KaTeX.
