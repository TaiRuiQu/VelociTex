# 1.0.0

VelociTex 1.0.0 unifies the formula pipeline on a single C++ core. The .NET
packages and the browser package now parse and render with the same code in
`native/core`; there is no separate JavaScript or Rust formula parser.

- The browser package loads `velocitex-core.wasm`, the C++ core compiled to
  WebAssembly. Its HTML, hidden accessibility MathML, inline styles and SVG
  fragments are byte identical to KaTeX 0.19.0 across **5,411 formulas**
  (1,605 real world formulas, the curated feature corpus, the frozen benchmark
  workloads and the repository fixture corpus), verified natively and in
  Chromium.
- The default browser path renders **3.9x faster than KaTeX 0.19.0** on the
  36-formula browser benchmark (about 43 vs 165 µs per formula, three-run
  median of 120 paired rounds in Chromium). The native C++ core renders the
  same corpus in **29.2 µs per formula**.
- The WebAssembly module is built with `-O3`, link time optimisation and a
  profile-guided layout collected from the acceptance corpus. The module uses
  the non-trapping float to int conversion and has no JavaScript imports beyond
  the WASI stub the loader provides.
- The vendored Rust HTML engine and its license are removed. The browser
  package ships only the C++ core, the locked KaTeX 0.19.0 stylesheet and the
  unchanged KaTeX fonts.
- The npm adapter keeps a synchronous fast path once the module is loaded, so
  the common `renderToString` call does not wait on a promise chain.

The default HTML output is the recommended browser path. `output: 'svg'`,
`fastHtml: false` and `fastMathml: false` continue to use the full .NET Core
runtime for the legacy SVG contract. Native .NET, Direct2D and WinUI packages
are unchanged at the API level.

Install the browser package with `npm install velocitex@1.0.0` (published under
`latest`). NuGet packages `VelociTex.Core`, `VelociTex.Rendering.Direct2D` and
`VelociTex.WinUI` share version `1.0.0`.

See [the benchmark guide](../benchmarks/README.md) for methodology and
reproduction, and [the package contract](../package-contract.md) for the
browser API.
